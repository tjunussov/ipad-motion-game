# iPad Motion Game

Native iPad motion-game experiment.

The player stands in front of the iPad camera and controls a simple game using body movement.

Initial POC:
- Apple Vision body pose tracking
- front camera
- punch detection
- jump detection
- squat detection
- primitive colored game objects
- no textures
- no backend
- no third-party ML stack

The goal is to keep the project small enough to vibe-code together over a weekend.

See [TRD.md](./TRD.md) for the implementation brief.
